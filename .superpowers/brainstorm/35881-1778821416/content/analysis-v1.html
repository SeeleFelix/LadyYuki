页面效果问题诊断报告

基于代码审查，我发现了以下 6 类潜在问题。请浏览后告诉我哪些最符合你的感受。

1. 视觉元素过载

每个 Chunk 800 颗星（dust/field/beacon），多 Chunk 同时可见意味着数千颗星。再加上：8 个星云、银河带、宇宙尘埃、流星、连接线、能量点、Fragment 星体、Void Gate、Whisper 轨迹、Cross Flare……所有元素同时渲染，缺乏分层和视觉优先级。

症状

  • 画面看起来很"忙"，不知道看哪里
  • 背景星和前景星座争夺注意力
  • 能量点和连接线的运动让人分心

2. 颜色一致性问题

Canvas 背景使用 #04040a，但 CSS 主题定义的是 #0a0a0f，存在不一致。Connection lines 的 outer glow 使用 8px 线宽但 alpha 很低（0.035-0.11），导致连线看起来像模糊的色块而非清晰的星座线。

症状

  • 暗部层次不够丰富
  • 连线缺乏锐利感，油腻模糊
  • 多种颜色（蓝/紫/粉/金/白）混在一起缺乏主次

3. 动画节奏混乱

近期 commit 添加了多个叠加动画：Connection line pulse（sine 0.7-1.0）, Energy dot pulse（sine 2.5Hz）, Star breath（0.5Hz）, Unread star pulse（2.5Hz）, Cross flare pulse（1.5Hz）。不同频率的脉冲叠加在一起可能产生不和谐的节奏。

症状

  • 同时看到多个元素以不同节奏闪烁
  • 动画缺乏统一的韵律感
  • 能量点的缓动曲线让其忽快忽慢

4. 缺乏视觉层级和焦点

所有 Fragment 星体使用相同的光晕渲染（super-outer bloom + outer halo + mid halo + inner glow），没有通过大小、亮度或颜色区分主次。void-entry 节点虽然特殊，但在视觉上与其他星体平权。

症状

  • 观众不知道应该先看哪里
  • 重要星体和普通星体视觉平等
  • 缺乏引导视线的视觉线索

5. 暗色背景缺乏深度

Vignette 效果从 75% 才开始有明显的黑色过渡，画面中心和边缘对比不够。背景色 #04040a 几乎纯黑，但星云和银河的 opacity 只有 0.004-0.03，在深色背景上几乎不可见，无法营造空间纵深感。

症状

  • 星空看起来像"平面贴图"而非立体空间
  • 星云和银河被深色背景吞没
  • 缺乏深邃宇宙的沉浸感

6. Void Chat 页面的 CSS 通配符问题

app.css 中的 * { transition-timing-function: ... } 规则对所有元素生效，可能导致 Void Chat 页面的布局变化出现意外的过渡动画，造成拖影或延迟感。

症状

  • 页面元素切换时有不自然的过渡
  • 消息出现时有拖尾或延迟
