# SeeleFelix

An ecosystem exploring **digital subjectivity** — the idea that AI + Prompt + Agent + Dialogue = Subject.

## Projects

| Directory | Description | Tech |
|-----------|-------------|------|
| **Portal/** | Immersive constellation portal — the main site | SvelteKit, TailwindCSS, Canvas API |
| **Welt/** | Knowledge world — philosophy (Geist) + project docs (Werk) | Quartz v4 |

## Quick Start

```sh
make install      # install all dependencies
make dev-portal   # start Portal dev server
make docs         # build + serve Welt, open browser
make build        # build everything
```
